# Aso Arena
<!-- impeccable:product-schema 1 -->
## Platform
web
## Stack
React, requested by the user; Three.js for real-time 3D.
## Purpose
A spectator watches AI-controlled, stylized fictional versions of Tinubu and Peter Obi fight in an arcade fighting game inspired by Tekken. No player combat controls are needed.
## Constraints
Clearly fictional political satire. Original generated character artwork and procedural environment, no copied game assets. Automatically running fights, rounds, health and spectator controls.
## Open decisions
Arena styling inferred as a dramatic night-time broadcast pending the optional user preference.

## Character direction
The user requested more realistic, detailed fighting-game characters after rejecting the initial toy-like models. Implemented with illustrated combat pose atlases on a 3D stage; the 2.5D approach was disclosed during the revision.

## Spectator presentation update
The user requested a bus stop with spectators filming, a short cinematic face-off before combat, and removal of all surrounding page chrome. The current game fills the viewport. Pause/settings are an overlay, with Space/Escape support; headers, footer, statistics and lower controls have been removed.

## Latest location correction
The user replaced the bus-stop/crowd request with a simple blank grassland. The full-screen layout and face-off intro remain requested.
